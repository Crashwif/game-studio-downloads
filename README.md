# Crashwif Game Studio downloads

Public installers for Game Studio, a desktop workspace for cloning Game Lab and remixing games with locally installed Codex and Claude Code CLIs.

[Download Game Studio](https://devnet.crashwif.com/studio/desktop) · [All releases](https://github.com/Crashwif/game-studio-downloads/releases)

Choose Windows x64 MSI, macOS Apple silicon or Intel DMG, or Linux x64 AppImage. Preview installers are unsigned and macOS builds are not notarized; Windows and macOS may show an unverified-publisher warning. Install only builds you trust.

Install Git, Node 24.11 or later within 24.x, npm 11, and your preferred coding CLI. Game Studio clones [Crashwif/game-lab](https://github.com/Crashwif/game-lab) into a folder you choose. Provider sign-in and credentials belong to the installed CLI. AI usage follows your provider account's plan and limits.

Each complete release includes all four installers, `SHA256SUMS.txt`, and `release.json` with the source commit and file hashes. Verify your download against its checksum. Windows uses an installation wizard; on macOS, open the DMG and drag the app to Applications. On Linux, make the AppImage executable and launch it with `--appimage-extract-and-run`.

This repository contains downloads and installation information. The platform source repository is separate. Desktop editing does not bypass the platform's publishing or fairness rules.
